# 饮水陪伴客户端 · Mac 首版

Tauri 2 + Vue 3。像素水豚直接在 Mac 顶部状态栏里播放工作、打盹、喝水和举瓶动作，旁边显示今日饮水量。左键在图标下方展开无标题栏的圆角浮窗，再次点击图标、点击外部或按 Esc 收起；切换应用或桌面空间也会收起。右键打开快捷菜单。浮窗收起后，状态栏动画和原生同步继续运行，只有“退出饮水陪伴”会停止程序。

## 使用

首次打开，填写已部署的服务根地址并测试连接，再使用现有账号登录。支持域名、IPv4、带方括号的 IPv6 和端口，例如 `water.example.com`、`http://192.168.1.8:3001`、`https://[2001:db8::1]:8443`。省略协议时使用 HTTPS，不需要 `/api`。注册、配网、空杯设置和历史记录管理通过“打开网页”进入现有网站。

服务端仍然校验 Host；客户端填写的入口需要与部署允许的地址一致。客户端保留证书验证，不跟随登录或 API 重定向。切换服务会取消旧请求、清除当前数据和旧会话，再登录新服务。

设置中可修改服务器地址、关闭自动休息或轻提醒。首次配置或需要登录时自动打开页面；已保存会话的日常启动只驻留顶部状态栏，点击水豚后再打开详情或设置。没有桌面悬浮卡片，也不显示 Dock 图标。

浮窗以菜单栏图标为中心，距图标下沿 4 个逻辑像素；靠近屏幕边缘时向内避让。详情、设置和重新打开应用均重新定位到图标；屏幕可用高度不足时缩短窗口，内容可滚动。Mac 原生窗口负责圆角、阴影和跨屏定位，沿用现有页面与后台同步。

## 开发与检查

需要 Node.js 24、Rust 1.88 或更新版本，以及 Xcode 命令行工具。Mac 最低版本为 macOS 13。仓库根目录执行：

```sh
npm ci
npm run dev:client
```

`dev:client` 只启动客户端开发页面和原生应用，不启动项目后端；使用已部署的服务。首次原生编译需要下载 Tauri 依赖。相关轻量检查：

```sh
npm run check:client
npm run check:client:native
npm run test:client:native
```

安装包构建、签名和公证不包含在这些检查中。当前版本未添加自动更新或开机启动。

## 开发更新与钥匙串授权

客户端读写、清除会话时均禁止钥匙串弹出系统授权窗口。无须配置开发证书；更新后若无法直接读取旧凭证，会打开客户端登录页并提示重新登录。重新登录沿用清除当前服务器旧凭证、保存新会话的流程；未更新时仍会尝试恢复登录。

凭证继续保存在 macOS 钥匙串中，不扩大条目的访问权限。系统“登录”钥匙串被锁定等情况下，客户端提示检查钥匙串状态，不自动弹出授权窗口。

## 数据与角色规则

- 原生进程通过现有 `/api/auth/*`、`/api/dashboard` 和 `/api/health` 通信。会话凭证只保存在原生内存和 macOS 钥匙串，前端快照不包含凭证，密码不落盘。
- 默认每 5 秒同步一次；失败后按 10、20、40、60 秒退避。详情窗口关闭不影响同步。界面使用原生快照序号丢弃迟到数据，服务/账号切换会取消旧网络请求。
- 观察到当前杯垫从有杯变为无杯后，水豚转向电脑的另一侧喝水，保持到杯子放回；仅拿杯不会增加饮水量或重置提醒。首次连接、重连、唤醒或更换绑定后的第一批数据只建立基线，杯子原本不在杯垫上时不补播。设备异常或断线会结束拿杯动作。
- 当前绑定、未撤销、首次出现且发生于最近两分钟内的饮水记录仍触发 4 秒喝水动作，放回确认后完成这段动作再恢复工作/休息。同批记录合并播放，补水记录不触发。拿杯状态沿用设备心跳与客户端每 5 秒同步，可能有数秒延迟；短暂取放若没有被同步捕获，仍可在饮水记录到达时播放动作。
- 累计活跃 60 分钟没有新饮水时举瓶 4 秒，每轮只提醒一次；新有效饮水（包括旧补传）重置计时。电脑空闲达到 5 分钟时休息，锁屏、断网、设备离线或异常期间不累计提醒时间。
- 忙闲仅查询系统空闲时长；休眠/唤醒使用系统工作区通知，锁屏补充观察 macOS 分布式状态通知。不会监听按键内容、申请输入监控或上传忙闲数据。系统通知兼容性仍需实机验证，查询失败时保持安静待机。
- 当前进程断线时保留最后成功数据及同步时间；重新启动后需要恢复会话和同步数据。按服务端日期/时区展示，离线跨午夜不把旧数据伪装成当天数据。
- 本机设置保存在系统应用配置目录的 `com.watercompanion.client/preferences.json`，不含密码或 Cookie。退出账号会清除本机凭证；网络不可用导致云端注销无法确认时会明确提示。
