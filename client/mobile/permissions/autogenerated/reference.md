## Default Permission

饮水陪伴本地安卓页面所需能力

#### This default permission set includes the following:

- `allow-configure`
- `allow-status`
- `allow-setCharacter`
- `allow-request`
- `allow-pinWidget`
- `allow-choose`
- `allow-connect`
- `allow-read`
- `allow-write`
- `allow-subscribe`
- `allow-disconnect`
- `allow-registerListener`
- `allow-removeListener`
