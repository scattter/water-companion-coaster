# 水豚动画素材

由内置 imagegen 于 2026-10-22 生成原创透明图集，提示词见 `prompt.txt`。`atlas.png` 保留生成原图；四行依次为工作、睡觉、喝水和举瓶提醒，每行四帧。未使用外部现有角色或图库素材。

初始图集为 1774 × 887，已按四等分网格拆帧并仅在右侧/底部补透明边，将每帧统一为 **444 × 222 RGBA PNG**。`icon.png` 为工作首帧按最近邻缩放、上下补透明边得到的 512 × 512 图标。

喝水四帧于同日用内置 imagegen 调整为朝左喝水，桌子和电脑仍在右侧，与朝右工作的姿势区分。新原图保留为 `drinking-atlas.png`（1774 × 887，2 × 2 排列），提示词见 `drinking-prompt.txt`。拆帧区域依次为 `(56, 78)`、`(943, 78)`、`(56, 483)`、`(943, 483)`，均为 806 × 382；按最近邻缩放到 352 × 167，再在 444 × 222 透明画布的 `(45, 53)` 处放置，保持各帧位置一致。`drinking-0.png` 至 `drinking-3.png` 已替换为这组帧，其他动作与原图不变。

`frames.json` 记录帧顺序；详情页与原生菜单栏共用 `<状态>-<0..3>.png`。渲染时保持宽高比，详情页使用像素化采样。所有帧已验证尺寸相同、有透明像素和可见像素；实际菜单栏 18 pt 高度下的清晰度、深浅色与帧切换仍需 Mac 实机验收。
