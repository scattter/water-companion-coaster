# 陪伴形象素材

默认形象为 `characters/robot.png` 中的 B 款小机器人：浅灰机身、蓝色眼睛和胸口横向灯条。2026-10-29 使用内置 imagegen 从已选方案提取为 1254 × 1254 透明 RGBA PNG，完整提示词见 `characters/robot-prompt.txt`。前端与托盘均保持全身比例，不使用场景图的上下裁切；安卓小组件复用同一原图。机器人目前为静态形象，水豚仍可选择并保留原有动画。

`icon.png`、Windows 的 `src-tauri/icons/icon.ico` 和 Android 工程内五档密度的启动图标，由 Tauri icon 工具从机器人原图生成。`icon.png` 用于应用图标，陪伴角色按本机设置加载；未保存选择或无效选择默认使用机器人，已有有效选择继续保留。

由内置 imagegen 于 2026-10-22 生成原创透明图集，提示词见 `prompt.txt`。`atlas.png` 保留生成原图；四行依次为工作、睡觉、喝水和举瓶提醒，每行四帧。未使用外部现有角色或图库素材。

初始图集为 1774 × 887，已按四等分网格拆帧并仅在右侧/底部补透明边，将每帧统一为 **444 × 222 RGBA PNG**。原应用图标由工作首帧生成，现已替换为上面的机器人图标。

喝水四帧于同日用内置 imagegen 调整为朝左喝水，桌子和电脑仍在右侧，与朝右工作的姿势区分。新原图保留为 `drinking-atlas.png`（1774 × 887，2 × 2 排列），提示词见 `drinking-prompt.txt`。拆帧区域依次为 `(56, 78)`、`(943, 78)`、`(56, 483)`、`(943, 483)`，均为 806 × 382；按最近邻缩放到 352 × 167，再在 444 × 222 透明画布的 `(45, 53)` 处放置，保持各帧位置一致。`drinking-0.png` 至 `drinking-3.png` 已替换为这组帧，其他动作与原图不变。

`frames.json` 记录帧顺序；详情页与原生菜单栏共用 `<状态>-<0..3>.png`。渲染时保持宽高比，详情页使用像素化采样。所有帧已验证尺寸相同、有透明像素和可见像素；实际菜单栏 18 pt 高度下的清晰度、深浅色与帧切换仍需 Mac 实机验收。

2026-10-29 新增 `characters/` 中的灰白小猫、奶油小狗、女生和男生四款静态形象，原图由内置 imagegen 参考水豚场景生成，完整提示词见 `characters/prompt.txt`。保留 1254 × 1254 RGBA PNG 原图，界面以 2:1 区域、`object-position: center 54%` 展示；原生托盘采用相同取景位置并预先缩到与水豚帧一致的尺寸，避免原图上下留白让角色过小。水豚继续使用原四状态动画，新角色在各状态下使用同一张静态图。

安卓小组件通过 Gradle assets 直接复用 `characters/` 原图；显示时按可见区域去掉透明留白，忽略 alpha 小于 16 的极淡噪点，再以最近邻采样限制到 444 像素宽，减少跨进程传递位图的内存。每种形象单独缓存，切换时更新所有组件尺寸。
