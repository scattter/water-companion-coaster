# 饮水陪伴杯垫

当前开发链路：**手机或 Mac 连接杯垫热点配网 → 杯垫连接家里 Wi-Fi → 上传电脑后端查看统计**。称重链路为 TAL220B → HX711 → ESP32-S3。

已移除称重模拟器、模拟控制、模拟接口和相关启动项。网页只展示真实设备上报的数据；未连接时不会生成重量或饮水记录。用 Arduino IDE 打开 [water_companion.ino](firmware/water_companion/water_companion.ino)，完整开发板设置、接线、配置和烧录流程见 [固件说明](firmware/README.md)。

当前实物为微雪 **ESP32-S3-LCD-1.47B** 和支持 3.3 V 供电的单 VCC HX711：**VCC→3V3、GND→GND、DT→GP2、SCK→GP4**。固件 **0.4.5** 上电开启配网热点，屏幕显示热点名、密码和地址。配网页直接由杯垫提供，无需启动电脑服务；已有 USB 命令和电脑上传继续可用。

0.4.5 修复取放漏记：拿起或放下时，杯子部分受力会短暂读到低于空杯的重量，现保留此前基准，等放稳后判断；稳定后仍低于空杯的异常读数继续作废。需要重新上传固件才生效，已有校准和记录格式不变。

## 连接热点配网

1. 用 Arduino IDE 重新上传 0.4.5 固件，保持“擦除全部 Flash”为 Disabled，以保留原有校准、联网配置和记录。
2. 手机或 Mac 的 Wi-Fi 连接屏幕上的 **Water-XXXXXX**，密码固定为 **12345678**。提示“无互联网”时选择继续连接；若保存过旧密码且无法重连，先忽略该网络再连接。
3. 浏览器打开 **http://192.168.4.1**，页面自动扫描附近的 **2.4 GHz Wi-Fi**。在下拉列表选择网络并输入密码，可点 **显示密码／隐藏密码** 核对，再点击 **保存并连接 Wi-Fi**；未找到时可重新扫描，隐藏网络可选择“手动输入”。无需先校准称重。
4. 保存结果通过可关闭浮窗提示，杯垫自动重启，热点会短暂断开。重新连接同一 Water- 热点，保持配网页打开；页首绿色卡片显示 **已经成功连接 XXX** 和局域网地址，才表示它已连上所填网络。再次访问也会直接显示实际连接状态；失败时可以修改后重试。
5. 将手机或 Mac 切回家里 Wi-Fi。杯垫以后上电自动连接已保存的网络，热点仍保留用于修改配置和空杯设置。

Mac 可使用 Safari 或 Chrome，配网步骤与手机相同。若旧版访问时只出现短小乱码或错误文字，需重新上传本版固件：已修正双栈 HTTP 连接被误拒绝的问题，并为中文错误响应明确指定 UTF-8。

日常称重在配网页下方的 **空杯与称重设置** 中：已校准时，放空杯、静置至少 3 秒，点击 **更新空杯重量**，之后正常加水取放即可。首次未校准才展开其中的“首次设置”，空载归零一次，再用已知重量的物品校准，最后更新空杯。可用另一台秤称准的空杯（50–2000 g），不必专门购买砝码。

HX711 原始差值仍需换算比例才能得到克数，不能靠空杯登记自动得出。因此保留一次性的重量校准，并从日常操作中收起。重启不会自动归零，已保存的校准继续生效。

手机页面每次检测设备未校时时会提交手机时间；请确保手机日期正确。杯垫本次启动中此前未校时的记录会回填时间，即使暂未连接电脑也会保存；跨断电且从未校时的旧记录仍需人工确认。页面“最近一次记录”只展示本次开机内的最近一条；完整已上传历史仍在电脑网页。关闭手机页面后，杯垫继续采样和保存。

Wi-Fi 配网成功不代表电脑后端已连通。已有后端配置继续沿用；尚未配置时，按下方步骤设置后端地址与设备凭证。配网失败仍可通过热点修改设置。

## 启动电脑端

需要 Node.js 24。先安装依赖并建立配置：

```sh
nvm use
npm ci
cp .env.example .env
node -e "console.log(require('node:crypto').randomBytes(32).toString('hex'))"
```

把生成的凭证填入 `.env` 的 `DEVICE_TOKEN`；`DEVICE_ID` 默认 `coaster-01`。已有 `.env` 时保留，不要重复覆盖或生成凭证。网页配置杯垫时，由后端通过 USB 写入相同的编号与凭证，浏览器不需要填写设备凭证。

```sh
npm run dev
```

打开 <http://127.0.0.1:5173>。启动器仅运行后端（3001）和网页（5173），按 `Ctrl+C` 一起停止。设备访问电脑的局域网 IP，例如 `http://192.168.1.10:3001`；不能使用 `127.0.0.1`、`localhost` 或 `0.0.0.0` 作为设备上报地址。

- 后端默认监听 `0.0.0.0`。只有带设备编号和凭证的设备上报接口接受局域网请求。
- 网页读取与撤销接口保持本机限制，网页在运行服务的电脑上打开。
- 电脑与杯垫接入同一可互通网络，允许电脑防火墙的 TCP 3001 入站。局域网 HTTP 仅供开发联调，不映射到公网。
- 网页关闭后，杯垫继续采样并上传；电脑服务停止后，设备把事件存到 Flash，服务恢复再补传。

网页会自动显示已连通后端的 Wi-Fi 设备，查看重量和统计无需选择 USB 串口。配置统一收在右上角“设置”中；检测到在线设备尚未校准时，首页显示“开始校准”，直接打开本页的校准操作，校准状态同步后自动隐藏。设置中的“Wi-Fi 配网”和“USB 备用设置”默认折叠，USB 展开后才读取串口。当前依据设备上报显示在线状态，尚未扫描局域网中的其他设备。

## 在电脑网页无线校准

若从不支持本页校准的版本更新，先重启电脑服务，再重新上传 **0.4.5 固件**，保留 Flash 数据；0.4.3 的局域网接口不支持电脑控制，页面会提示升级。已使用 0.4.4 本页校准时，只需上传 0.4.5 修复取放漏记。电脑与杯垫保持同一可互通的网络，设备已配置后端并显示在线后：

1. 在 **http://127.0.0.1:5173** 点击“开始校准”，或从右上角“设置”进入。
2. 移走杯子和其他物品，静置至少 3 秒，点击“空载归零”，等待设备确认。
3. 放上已知重量的物品，输入实际克数（50–2000 g），静置后点击“保存重量校准”。
4. 换成日常空杯，静置后点击“更新空杯重量”，成功后即可加水使用。

全程留在 5173，无需切换热点或选择 USB。日常换杯从“设置”直接更新空杯，不重新归零。后端从已认证心跳取得杯垫地址，携带设备凭证读取状态并发送校准；浏览器不接触凭证。写入超时不自动重试，也不显示成功，应刷新设备状态后再继续。设备未联网时仍可选择热点页或 USB 校准。

## 电脑 USB 设置与可选上传

1. 启动服务后，将杯垫通过 USB 数据线连接这台电脑，**关闭 Arduino 串口监视器**，避免占用端口。
2. 点击网页右上角“设置”，展开“USB 备用设置”，选择 `/dev/cu.usbmodem...` 等实际开发板端口，点击“连接 USB”。未列出时点击“刷新端口”。热点配网请使用 0.4.5，USB 入口兼容 0.3.1；若仍显示引导分区错误，先修正 Flash 设置并重新上传。
3. 输入 **2.4 GHz Wi-Fi** 名称和密码，选择与杯垫同一网络的电脑局域网地址，点击“保存并重启杯垫”。多个地址时选择实际 Wi-Fi／有线接口的地址，不选不相通的 VPN 网段。后端自动写入设备凭证。
4. 等待板载屏幕分别显示 Wi-Fi 与服务器连接成功，网页显示“设备在线”。USB 连接只说明串口可用，不能代替联网确认。
5. 重启后重新连接 USB；端口变化时先刷新列表。日常只需放空杯、静置三秒，点击“更新空杯重量”。
6. 首次未校准时再展开“首次设置”，依次空载归零、用已知重量校准、更新空杯。每步看到成功反馈再继续；不稳定时会显示固件错误。

校准保存在杯垫中，立即生效，不需重启。再次归零会清除砝码校准和空杯登记；换杯通常只需重新登记空杯。校准可在 Wi-Fi 尚未连通时通过 USB 完成。配置好后可断开网页 USB 连接；杯垫持续供电、电脑后端持续运行即可通过 Wi-Fi 上报。

网页经本机后端访问 USB 串口，无需浏览器的 Web Serial 或蓝牙配对。连接失败时先关闭其他占用串口的工具；超时或拔线后需重新连接，网页不会把未收到确认的写入标记为成功。

## 第一条真实记录

1. 按 [接线表](hardware/circuits/wiring.md) 安装开发板、HX711 和传感器。
2. 在 Arduino IDE 中按 [固件说明](firmware/README.md) 验证并上传，完成配网和后端配置后，在电脑网页“开始校准”；离线也可使用热点页。
3. 首次完成重量校准后，放空杯并“更新空杯重量”；已校准的设备可直接更新空杯。
4. 杯中加水并稳定；取杯移除已知水量，再放回等待约两秒，核对手机页面最近一条差值及保存状态。
5. 验证补水、撤销、断网补传、重启后校准值和历史保持。

清水按 1 g ≈ 1 ml 估算；倒水和喝水无法只凭重量区分，喝完直接补水只能得到净变化。

## 检查与验收

```sh
npm run typecheck
npm test
npm run test:firmware
```

后端测试使用项目内独立临时数据库；固件测试编译实际 C 称重模块、Wi-Fi 扫描函数与 HTTP 访问校验函数，并在 Node 中测试内置手机页的请求与状态逻辑。不会监听端口、启动服务或执行 Arduino 整体构建。已执行检查和待真机验证项见 [验收记录](docs/validation.md)。

## 目录与数据

```text
firmware/water_companion/ Arduino 工程、HX711、手机热点页、串口配置和事件缓存
hardware/components/    采购清单
hardware/circuits/      接线与承重安装说明
server/                 Fastify API、USB 串口配置、SQLite、统计与撤销
web/                    Vue 仪表盘、USB 设置与校准、真实设备状态
docs/                   接口协议和验收记录
```

真实设备数据库默认在 `data/coaster-hardware.sqlite`，使用 `device_events` 与 `device_status` 表。原有演示文件不读取、不混入真实统计；旧数据未自动删除。数据库、凭证和测试输出均不入 Git。

这是单台设备的开发联调版本。当前 0.4.5 的 Arduino 完整编译、烧录、屏幕实显、手机／Mac 热点配网、USB 实机配置、称重精度、Flash 断电恢复与实际联网仍需验证；按钮互动、蓝牙配网、用户登录绑定和双人陪伴按 `PLAN.md` 后续推进。
