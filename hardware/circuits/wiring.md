# 单台杯垫接线与安装

更新：2026-10-24（底板布局 v1.3c：沿用 v1.3 的 ADC 电量采样电路与接口）。适用：微雪 ESP32-S3-LCD-1.47B + TAL220B 2 kg + 用户已确认支持 3.3 V 供电的单 VCC HX711 板。HX711 引脚见 [board_config.h](../../firmware/water_companion/board_config.h)；实际接线逐项核对模块丝印。

## 底板 v1.3 与电量采样

当前底板使用 ADC 分压采样，完整工程、生产资料及装配位置见 [v1.3c 说明](carrier-v1.3.md)。本次将 LED1 移至 BAT 右侧并增加中文极性丝印，接口位置、方向和针序保持不变；生产请配套使用 v1.3c Gerber 与贴片坐标。旧 [v1.2 MAX17048 方案](carrier-v1.1.md)仅用于旧板对照。

| 连接 | 用途 |
| --- | --- |
| BAT_CELL → R4 100k → R5 100k → BAT_SENSE | 两颗串联组成 200 kΩ 上臂 |
| BAT_SENSE → R6 100k → GND | 100 kΩ 下臂 |
| BAT_SENSE → C4 100nF → GND | 采样滤波 |
| BAT_SENSE → J_DEV_B-8 / GPIO5 | ADC1_CH4，名义电池电压为 ADC 电压的 3 倍 |
| J_DEV_B-9 / GPIO6 | 底板 NC |

R4、R5、R6 为新增的三颗 C25803；C4 为 C14663。原有 R2 仍用于充电隔离，整板共四颗 100 kΩ。新板不再安装 5580 模块、六针座或模块支柱。

电池直接接底板 J_BAT；J_BAT-1 为正、2 为负，从顶面图看分别为右、左焊盘。必须测量电池插头正负极后连接。开发板原电池口留空，避免绕过底板充电隔离。采样取隔离前的 BAT_CELL，不能短接 BAT_CELL 与 BAT_DEV。HX711 的 GPIO 分配与 v1.2 针序保持不变。

硬件采样电路已完成，固件尚未增加几格电量与低电提醒。后续应在 GPIO5 配置 ADC、校准电压、平均滤波并设置回差；充电和负载变化下的显示阈值须实测。不要再将 GPIO5 配置为 I²C SDA。

开发板顶面丝印：LCD 朝上、USB 朝左时，上排从左到右为 5V、GND、3V3、IO0、IO2、IO3、IO4、IO5、IO6；下排为 TX、RX、BAT、GND、IO11、IO10、IO9、IO8、IO7。未用 GPIO 保持底板 NC。

## HX711 与开发板

用户已确认：从 HX711 的 VCC 一端沿排针依次为 **VCC、SCK、DT、GND**。底板 v1.2 / v1.3 顶面、开发板 LCD 朝上且 Type-C 朝左时，J_HX 从左到右对应 **1=VCC/3V3、2=SCK/GPIO4、3=DT/GPIO2、4=GND**。旧 v1 / v1.1 的第 2、4 脚顺序相反，已有旧板必须按名称逐根转接；新板使用更新后的制造文件。

| HX711 引脚 | 开发板引脚 | 用途 |
|---|---|---|
| DAT / DT / DOUT | GP2（GPIO2） | ADC 数据与就绪信号 |
| CLK / SCK | GP4（GPIO4） | 串行时钟 |
| VCC | 3V3（OUT） | 模块与桥路供电，数字侧使用 3.3 V 电平 |
| GND | GND | 共地 |

已按[微雪引脚图](https://docs.waveshare.net/ESP32-S3-LCD-1.47B/)和[官方原理图](https://files.waveshare.com/wiki/ESP32-S3-LCD-1.47B/ESP32-S3-LCD-1.47B_schematic_diagram.pdf)核对：GPIO1 用于板载电池电压检测，没有引出；GP2、GP4 已引出且未占用板载 LCD、IMU 或 SD 卡信号。背面朝自己、Type-C 在上方时，GP4 是左排倒数第 3 个引脚。

当前 HX711 没有独立 VDD，无需补接；VCC 接 3V3，不接 5V、VBAT 或 VSYS。旧采购单中 VCC=5 V、VDD=3.3 V 的说明仅适用于分离供电板，不能套到当前模块。更换模块后需要重新核对电路与供电范围。

HX711 使用 A 通道、128 倍增益和 10 SPS。核实 RATE 焊桥／引脚处于 10 SPS 配置；不要接 B 通道。改线前断开 USB 电源，接好后先检查短路、共地和 3.3 V 数字电源。

## 传感器与 HX711

| 传感器定义 | HX711 |
|---|---|
| 激励正 E+ | E+ |
| 激励负 E− | E− |
| 信号正 S+ / A+ | A+ |
| 信号负 S− / A− | A− |

按传感器资料确认功能，不只根据线色接线。四根线需可靠端接／焊接并做应力释放。固件允许正或负校准系数，因此加载时 ADC 增大或减小都可标定；应先确认接的是完整桥路。

## 承重结构

一端固定底板，另一端通过垫块支撑上盘，梁体形变区留空。上盘不能接触固定外壳、限位或跨接硅胶；线缆留余量，避免拉力分担载荷。2 kg 量程包含上盘、杯子和水，去零不会增加机械量程。

先验证空载、砝码、中心与偏心放杯，之后再验证热杯静置。微雪开发板已带 1.47 英寸屏幕，当前称重固件尚未驱动屏幕或使用按钮，后续固定在底座位置。

## 首次检查

1. 用 Type-C 数据线连接电脑，按[固件说明](../../firmware/README.md)打开 `.ino` 并上传；在 Arduino 串口监视器选择 115200 和“新行”，确认启动信息打印 DOUT=GP2、SCK=GP4。
2. 发送 `{"cmd":"watch","enabled":true}`，确认 `raw` 随真实载荷改变且静置后收敛。
3. HX711 未就绪、饱和或无连续有效样本时应提示错误，不能跳过校准继续记录。
4. 按 [固件说明](../../firmware/README.md)执行零点、砝码与空杯登记，使用第二个已知质量复核。
